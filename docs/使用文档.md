# 使用文档

本文档面向部署后的**管理员**与**用户**，说明系统各功能的使用方法。

## 一、管理后台

后台地址：`https://你的域名/admin`（默认账号 `admin` / `admin123456`，**首次登录请立即改密**）。

### 1. 对接配置

系统所有 AI 能力来自上游平台。在「对接配置」页填写：

- **对接域名**：上游 openapi 通道根地址（保存后写入 `config/docking.php`）
- **对接 Token**：上游签发的 Bearer 凭证
- **agent_str 前缀**：默认 `adweb_`，一般无需修改

配置保存后，可在本页查看上游账户余额，验证对接是否连通。

### 2. 商品管理（计费核心）

每个商品对应一个业务能力。**用户价 = 进价 + 加价**：

- **加价（元/次 或 元/千字）**：你希望的利润空间，后台逐商品设置
- **进价**：来自上游底价。点击商品卡的「获取对接底价」可自动拉取上游成本价
- **首页默认商品**：勾选后，用户端首页 `/pc/` 自动跳转到该商品页面；同时该商品在侧栏置顶
- **排序**：侧栏菜单按 默认商品 → sort_order 升序 排列
- **启用/停用**：停用的商品不在用户端显示

商品类型说明：

| 类型 | 商品 | 计费模式 |
| --- | --- | --- |
| 直购 | AI论文、AI检测、格式重排 | 按次/按字数计费 |
| 直购（后付费） | PPT生成、格式重排 | 下单不扣费，**下载时扣费** |
| 工具 | 段落改写、配图、图表、参考文献、题目/大纲生成 | 按次计费 |
| 资源包 | 降重降AI资源包、AI检测资源包 | 套餐加价载体，购买后即时到账 |

### 3. 支付管理

支持四种渠道：**余额支付**（站内余额，始终可用）、**微信支付**、**支付宝**、**易支付**。

- 在「支付管理」中填写商户参数（商户号 / AppID / 密钥 / 证书等），全部参数留空或未启用时渠道不显示
- 微信/支付宝使用官方商户资质；易支付填第三方聚合支付的 pid/key/网关地址
- 支付回调地址由系统自动生成，微信/支付宝商户后台无需额外配置回调（如需手动配置，回调入口为 `https://你的域名/pay.php`）

### 4. 充值赠送规则

可按金额区间设置赠送：**比例赠送**（如充 100 送 10%）或**固定赠送**（如充 100 送 20）。
多条规则按区间匹配，赠送金额随充值订单自动入账并记录流水。

### 5. 邮箱配置

填写 SMTP 服务器信息（主机 / 端口 / 账号 / 密码 / 加密方式 / 发件人），用于：

- 用户注册/找回密码的邮箱验证码
- 站内邮件通知

未配置时相关邮箱功能不可用（不影响其他注册方式）。

### 6. 第三方登录

- **微信扫码登录**（微信开放平台应用）：填写 AppID / AppSecret 后开启，用户端登录弹窗出现「微信扫码」选项
- **互联登录**（QQ/微信等聚合登录）：填写互联平台地址与密钥后开启
- 均未开启时，用户端仅显示账号密码登录

### 7. 客服配置与公告

- **客服配置**：设置客服邮箱/电话/QQ/微信号与工作时间，用户端展示悬浮客服按钮
- **公告管理**：发布站内公告，用户端公告位展示

### 8. 用户与资金

- **用户管理**：查看/检索本站用户，可调整余额（平台调整会记录资金流水）
- **资金明细**：每一笔充值、消费、赠送、调整都有流水记录（含 change_type 类型与关联订单号）
- **订单管理**：按业务类型查看订单状态、内容与扣费信息

## 二、计费模型（重要）

本站采用**双余额**模型：

1. **本站余额**：用户在本站充值获得的余额，所有扣费先走本站余额
2. **上游预充**：你在上游平台预充的对接资金，系统对上游的一切调用都会核销该预充

- 用户可见的价格永远 = 进价 + 加价；上游预充余额**不会**透出给用户
- 部分业务（PPT、格式重排）为**后付费**：下单仅创建订单，用户点「下载」时才扣费
- 用户消费流水含本站归因（agent_str），上游对账时可按前缀区分来源站点

## 三、用户端使用

用户端地址：

- PC 端：`https://你的域名/pc/`
- H5 移动端：`https://你的域名/m/`（手机浏览器访问，底部 Tab 导航）
- 直接访问 `https://你的域名/` 时系统按浏览器 UA 自动分流到对应端

### 注册 / 登录

- 右上角「登录」按钮唤起**登录弹窗**（账号密码 / 微信扫码，扫码入口视后台开关显示）
- 支持邮箱/手机号验证码注册（验证码依赖邮箱配置）

### 充值

- 个人中心 →「余额充值」，选择金额与支付方式，扫码支付后弹窗自动关闭并刷新余额
- 充值赠送按后台规则自动入账

### 业务使用

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| AI 论文 | 侧栏「AI 论文」 | 输入题目/大纲生成论文，支持私有模板、范文参考、段落续写 |
| AI PPT | 侧栏「PPT 生成」 | 标准/高级双版本；后付费，下载时扣费 |
| 开题报告 / 任务书 / 实习报告 / 实习日志 | 侧栏对应菜单 | 按表单生成，支持批量日期 |
| AI 检测 | 侧栏「AI 检测」 | 检测文本/文档 AI 率 |
| AIGC 降重 | 工具区 | 段落/文档降 AI 率，支持时长包/字符包抵扣（视上游配置） |
| 格式重排 | 侧栏「格式重排」 | 上传 docx 按模板排版，后付费 |
| 小工具 | 工具区 | 段落改写、配图、图表、参考文献、题目/大纲生成 |

### 个人中心

- **账户总览**：余额、消费/充值统计、近 7 日趋势、最近资金变动
- **余额充值 / 金额变动 / 套餐余额 / 账号设置**：自助管理
- 套餐余额展示已购资源包（降重降AI资源包 / AI检测资源包）的剩余量

## 四、日常运维建议

- 定期备份：数据库 + `public/uploads/` + `.env` + `config/site.php`
- 上游对账：后台资金明细可导出核对，注意后付费业务扣费发生在下载时
- 数据量大后执行部署文档中的三条索引 SQL，保证统计页面性能
- 升级前端：重新构建后整目录覆盖 `public/pc` 与 `public/m`，用户端自动强刷到新版本
