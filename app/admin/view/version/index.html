后端执行顺序

以下步骤由服务端状态机顺序执行；任一步失败将中止任务并写入日志，可在下方查看明细。

  2. 2 下载更新包并校验完整性
  3. 3 备份当前文件
  4. 4 应用文件与数据库迁移
  5. 5 健康检查

离线更新

当在线通道不可用时，使用官方分发的 zip 包在本机应用更新。请先完整阅读说明再选择文件。

使用前请确认

  • 更新包须为官方提供的 .zip，来源不明文件可能导致站点无法访问。
  • 应用前建议完成数据库与站点文件备份，并在低峰期操作。
  • 上传成功后，「应用离线更新」才会生效；应用过程请保持浏览器会话有效。
  • 若同时存在进行中的在线升级任务，请先等待其结束或处理异常后再操作离线更新。
