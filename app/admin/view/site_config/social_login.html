2 微信服务号·关注公众号登录

配置存储：ad_system_config.config_key = social_wx_mp_config（与开放平台、聚合登录独立）

用户扫码关注或已关注后扫码，公众号内会回复下方配置的欢迎词（默认「登录成功」类提示），电脑端自动登录。请在公众平台 开发 → 基本配置 中：

  • 服务器 URL：（与下方 Token 配套，HTTPS）
  • Token：与下方输入框一致
  • 消息加解密：选明文模式时可不填 EncodingAESKey；选兼容模式 / 安全模式时须在下方填写与公众平台一致的 EncodingAESKey（43 位）
  • IP 白名单：填网站服务器访问微信接口的出口公网 IP；报 invalid ip 时把提示里的 IP 加进去
