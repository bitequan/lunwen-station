API 概述

系统简介

TokenAPI 是一个功能完善的写作服务接口系统，提供多种写作类型和工具集合，支持开题报告、任务书、实习报告、高级论文、PPT生成等多种业务场景。

系统采用 RESTful API 设计，支持 JSON 格式的数据交互，提供完善的鉴权机制和错误处理。

主要功能模块

1. 基础写作功能

包括开题报告、任务书、实习报告、实习日志等基础写作类型的完整流程管理。

2. 高级论文功能

提供论文表单配置、图表资源、文献资源、大纲生成、模板管理等高级功能。

3. PPT生成功能

支持PPT价格查询、大纲生成、模板管理、订单处理、预览下载等功能。

4. 工具集合

提供参考文献获取、段落改写、段落配图、AIGC降重、图表生成、题目生成、大纲生成等实用工具。

5. 模板管理

支持大纲模板和论文模板的增删改查、状态管理等操作。

6. 支付功能

提供价格查询、余额支付等支付相关接口。

接口特点

• 统一响应格式：所有接口采用统一的 JSON 响应格式，便于处理

• 完善的错误处理：提供详细的错误码和错误信息

• 灵活的鉴权机制：支持多种鉴权方式，保障接口安全

• 丰富的功能模块：覆盖写作服务的各个环节

• 详细的文档说明：每个接口都有详细的参数说明和示例

快速开始

1. 查看 鉴权方式 了解如何获取和使用 Token

2. 查看 响应格式 了解接口返回的数据结构

3. 根据业务需求选择相应的功能模块进行对接

4. 参考各模块的接口文档进行开发和测试
