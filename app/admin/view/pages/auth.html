鉴权方式

Token 认证

所有 API 接口都需要通过 Token 进行身份验证。Token 需要在请求头中传递。

Authorization: Bearer YOUR_TOKEN_HERE
注意：请妥善保管您的 Token，不要将其暴露在客户端代码中。建议将 Token 存储在服务器端，通过后端代理的方式调用 API。

请求头示例

在发送请求时，需要在 HTTP 请求头中包含以下信息：

GET /tokenapi/write_type/list HTTP/1.1 Host: api.example.com Authorization: Bearer YOUR_TOKEN_HERE Content-Type: application/json

获取 Token

Token 需要通过以下方式获取：

  1. 联系系统管理员申请 API 访问权限
  2. 管理员会为您分配一个唯一的 Token
  3. 使用该 Token 进行 API 调用

Token 有效期

Token 具有以下特性：

项目 说明
有效期 Token 长期有效，除非被管理员手动撤销
权限范围 Token 拥有该账户下的所有 API 访问权限
安全建议 定期更换 Token，避免泄露

错误处理

当 Token 无效或过期时，API 会返回以下错误：

{ "code": 401, "msg": "未授权，请检查 Token 是否正确", "data": null }

如果遇到此错误，请检查：

  • Token 是否正确传递
  • Token 是否已过期或被撤销
  • 请求头格式是否正确
