响应格式

统一响应结构

所有 API 接口都采用统一的 JSON 响应格式：

{ "code": 1, "msg": "success", "data": { // 具体数据内容 } }

响应字段说明

字段 类型 说明
code int 状态码，1 表示成功，其他值表示失败
msg string 响应消息，成功时通常为 "success" 或空字符串，失败时包含错误信息
data object/array 响应数据，具体结构根据接口而定，失败时可能为 null

成功响应示例

成功响应：
{ "code": 1, "msg": "success", "data": { "id": 1, "name": "示例数据", "status": "active" } }

错误响应示例

错误响应：
{ "code": 0, "msg": "参数错误：title 不能为空", "data": null }

常见状态码

状态码 说明
1 请求成功
0 请求失败，具体错误信息在 msg 字段中
401 未授权，Token 无效或过期
403 禁止访问，权限不足
404 资源不存在
500 服务器内部错误

数据处理建议

在处理 API 响应时，建议按照以下步骤：

  1. 首先检查 code 字段，判断请求是否成功
  2. 如果 code === 1，则处理 data 字段中的数据
  3. 如果 code !== 1，则根据 msg 字段显示错误信息
  4. 对于特殊状态码（如 401、403），需要特殊处理（如重新登录）
